# Security policy

Please do not publish sensitive URLs, credentials, tokens, or personal data in issue reports. For a suspected vulnerability in the project itself, contact the maintainers privately before public disclosure. Provide the affected version, impact, and a minimal reproduction using inert test input. Do not include live malicious destinations or instructions for exploiting third-party systems.

PhishGuard is an offline text analyzer, not a guarantee that a URL is safe. Public deployment requires a separate security review, TLS, authentication, rate limiting, monitoring, and an explicit data-retention policy.
